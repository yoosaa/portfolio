# Studio scene editing guide

このファイルは、3Dトップ画面をあとから自分で調整するための操作メモです。

主に触るファイルは次の3つです。

- `../StudioScene.tsx`: 部屋・家具・小物・ライトの形と配置
- `CameraRig.tsx`: カメラ遷移と、既存オブジェクトへの後付け調整
- `../../model/scene-config.ts`: 各カメラの座標、注視点、FOV、遷移時間

---

## 1. 座標系

React Three Fiber / Three.jsでは、基本的に次の向きで考えます。

- `x`: 左右。プラスで右、マイナスで左
- `y`: 高さ。プラスで上、マイナスで下
- `z`: 奥行き。現在のカメラ構図では、値の変化が前後移動として見える

この部屋では左壁と奥壁があるため、壁際のオブジェクトは座標を少し変えるだけで壁の裏へ潜ることがあります。
特に窓は左壁に沿って90度回転しているため、通常の正面向きオブジェクトと奥行き方向の感覚が違います。

---

## 2. 高さの基準

`StudioScene.tsx` 冒頭の定数が、部屋全体の高さ基準です。

- `BASE_TOP`: 一番下の床面
- `LOWER_FLOOR_TOP`: 青とベージュの手前エリアが乗る面
- `UPPER_FLOOR_TOP`: 緑とオレンジの奥側エリアが乗る面
- `MAT_THICKNESS`: 各色マットの厚さ
- `LOWER_MAT_TOP`: 手前マットの上面
- `UPPER_MAT_TOP`: 奥側マットの上面

家具を床へ置くときは、固定値だけでなく `LOWER_MAT_TOP` または `UPPER_MAT_TOP` を基準にすると、床の高さを変更しても追従しやすくなります。

### 注意

`UPPER_FLOOR_TOP` を変更すると次が同時に影響を受けます。

- 上段床の高さ
- 階段の段差
- 本棚、コルクボードなど上段の家具
- 壁に取り付けた小物の見え方

上段だけを見た目で上下させたい場合も、まず家具を個別に動かすより、高さ基準との関係を確認してください。

---

## 3. `position` と `scale`

```tsx
<group position={[x, y, z]}>
```

グループ全体を移動します。
家具一式を動かす場合は、子要素を一つずつ変更せず、一番外側の `group` の `position` を変えるのが安全です。

```tsx
<Box scale={[width, height, depth]} />
```

`scale` はこの実装では、おおむね幅・高さ・奥行きとして使っています。

- 1番目: 横幅
- 2番目: 高さ・厚み
- 3番目: 奥行き

家具のパーツ判定に `scale` を利用している箇所が `CameraRig.tsx` にあります。
そのため、机・本棚・コルクボードの特徴的なパーツの `scale` や色を変えると、後付け処理が対象を見つけられなくなることがあります。

---

## 4. 部屋全体の構造

`Room` コンポーネントが、シーン内の大きな配置をまとめています。

ここには主に次が置かれています。

- ベース床
- 青い作業エリアのマット
- 手前右側のベージュマット
- 上段床
- 緑・オレンジのマット
- 階段
- 壁
- 机、本棚、コルクボード、窓、植物など

### 部屋全体の見え方を調整するとき

最初に確認する順番は次の通りです。

1. `Room` 内の床と壁
2. 家具コンポーネント外側の `group position`
3. `scene-config.ts` の初期カメラ
4. ライトと影

家具の細部から触るより、まず大きなシルエットと構図を合わせる方が崩れにくいです。

---

## 5. 階段

`LevelStairs` は、`fromY` から `toY` までを `stepCount` で分割して段を作ります。

主な調整値:

- `position`: 階段全体の配置
- `fromY`: 一番下の基準
- `toY`: 一番上の基準
- `stepCount`: 段数
- `width`: 横幅
- `treadDepth`: 一段の奥行き

### 注意

`stepCount` を変えると一段あたりの高さも変わります。
`treadDepth` だけを大きくすると、階段全体が前後へ長くなり、床へめり込んだり上段からはみ出したりします。

階段を調整したら、最低でも次を確認します。

- 最上段が上段床とつながって見えるか
- 最下段がベース床から浮いていないか
- 階段の正面が机や小物と干渉していないか

---

## 6. 机とモニター

`Desk` の一番外側の `group position` が机全体の配置です。

机の中には次が含まれます。

- 天板
- 元の左右収納
- モニター
- キーボード
- マグカップ
- ノートとペン

現在は `CameraRig.tsx` 側で、元の左右収納と取っ手を非表示にし、細い脚を後付けしています。

### 机全体を移動する

`Desk` の外側 `group position` を変更します。
モニターをクリックしたときの画面も合わせて動かす場合は、`scene-config.ts` の次も調整します。

- `DISPLAY_CAMERA_POSITION`
- `DISPLAY_LOOK_AT`

### モニターだけを動かす

`Desk` 内のモニター用 `group` を変更します。
この場合も `DISPLAY_LOOK_AT` の見直しが必要です。

### 注意

現在の後付け処理は、天板や収納の色と `scale` を手掛かりに机を判定しています。
次の値を変更した場合は `CameraRig.tsx` の判定も確認してください。

- 天板色 `#6176bd`
- 天板 `scale={[3.42, 0.3, 1.58]}`
- 左収納と右収納の色・scale
- 引き出し取っ手の色・scale

---

## 7. 本棚

`Bookshelf` の一番外側の `group position` が本棚全体の位置です。

現在は `CameraRig.tsx` 側で、次の後付け調整があります。

- 一部の本を非表示
- 上部の植木鉢を非表示
- 収納箱を追加
- 小さな額を追加

### 本棚全体を移動する

`Bookshelf` の外側 `group position` を変更します。
同時に `scene-config.ts` の次も動かします。

- `BOOKSHELF_CAMERA_POSITION`
- `BOOKSHELF_LOOK_AT`

### 注意

後付け処理は背板の色と `scale` から本棚を判定しています。
次を変更すると判定が外れる可能性があります。

- 背板色 `#70927f`
- 背板 `scale={[2.02, 2.98, 0.12]}`

本の非表示判定には、本の色・ローカル座標も利用しています。
本を大幅に並べ替える場合は、`CameraRig.tsx` の `bookshelfGroupRef` 周辺も一緒に確認します。

---

## 8. コルクボード

`Corkboard` の外側 `group position` が全体位置です。

現在は `CameraRig.tsx` 側で次を行っています。

- 元の均一な3枚のメモを非表示
- サイズと角度が異なるメモを追加
- ピンを追加
- 下部の細い棚を追加

### 全体を移動する

`Corkboard` の外側 `group position` を変更します。
カメラも合わせて、次を調整します。

- `CORKBOARD_CAMERA_POSITION`
- `CORKBOARD_LOOK_AT`

### 注意

後付け処理はボード色と `scale` を使って対象を見つけています。

- ボード色 `#b96d5d`
- ボード `scale={[2.08, 1.58, 0.16]}`

元メモの色も非表示判定に使われています。

---

## 9. 窓

窓は左壁に沿わせるため、外側 `group` に次の回転があります。

```tsx
rotation={[0, Math.PI / 2, 0]}
```

このため、窓グループ内のローカル `z` を変更したとき、画面上では左壁へ潜る・手前へ出る動きになります。

### 安全な調整

- 窓全体の上下: 外側groupの `position` の `y`
- 壁に沿った左右: 外側groupの `position` の `z`
- 窓サイズ: 枠・ガラスを同じ比率で変更

### 危険な調整

- 根拠なく窓全体のローカル奥行きを増減する
- 枠だけ厚くし、ガラスの位置を合わせない
- 窓の周囲へ大きな箱を追加する

これらは、窓ガラスが壁へ隠れたり、扉のような見た目になりやすいです。

窓を移動した場合は、次も見直します。

- `WINDOW_CAMERA_POSITION`
- `WINDOW_LOOK_AT`

---

## 10. 植物

`Plant` は外側 `group` の `position` と `scale` で配置します。
葉はクリック時に軽く動くため、床や壁へ極端に近づけると揺れたときにめり込みます。

植物を小さくしたい場合は、鉢や葉を個別に変更せず、まず `scale` を変更します。

```tsx
<Plant position={[x, y, z]} scale={0.7} />
```

## 11. `CameraRig.tsx` の役割

`CameraRig.tsx` には大きく2種類の処理があります。

### カメラ遷移

`phase` に応じて、`scene-config.ts` のPOSITION・LOOK_AT・FOVへ補間します。

- 初期表示
- ディスプレイ
- 本棚
- コルクボード
- 窓

`CAMERA_TRANSITION_DURATION` が遷移時間です。

### 後付けの見た目調整

現在はシーンを `traverse` して、色・scale・位置を手掛かりに既存オブジェクトを探しています。
見つけた後、次のような処理をします。

- 壁色をクリーム色へ統一
- ペンダントライトを非表示
- 壁の額を追加
- 机の収納を非表示にし、脚を追加
- 本棚の一部を差し替え
- コルクボードのメモを差し替え

これは見た目を素早く調整するための後付け処理です。
`StudioScene.tsx` 側の元オブジェクトを変更すると、判定条件が一致しなくなる可能性があります。

### `restoredVisibility`

非表示にする前の `visible` を保存し、アンマウント時に元へ戻すためのMapです。

### `addedObjects`

後付けしたオブジェクトを記録し、アンマウント時に削除・disposeするための配列です。
これを通さずオブジェクトを追加すると、開発中の再マウントで重複する可能性があります。

### 後付けオブジェクトを追加するとき

1. `create...` 関数で `THREE.Group` を作る
2. 対象groupへ `add`
3. `addedObjects.push` へ登録
4. geometryとmaterialが `disposeObjectTree` で破棄できる構造にする

## 12. カメラの調整方法

まず `scene-config.ts` を触ります。

### カメラを対象へ近づける

対象とカメラの距離を縮めます。
FOVを小さくしても拡大できますが、見え方が望遠寄りになります。

### 上から見たい

`*_CAMERA_POSITION` の `y` を増やします。
必要に応じて `*_LOOK_AT` の `y` も調整します。

### 対象を画面中央へ動かしたい

`*_LOOK_AT` を調整します。
ただし対象そのものが大きくずれている場合は、カメラではなくオブジェクト位置を直す方が自然です。

### FOV

- 小さい: 望遠。奥行きの歪みが弱い
- 大きい: 広角。広く映るが、近い物が大きく見える

初期部屋表示はアイソメトリック風に見せるため、個別表示より小さなFOVにしています。

---

## 13. ライトと影

影の見え方には主に次が関係します。

- ライトの位置・強さ
- 各meshの `castShadow`
- 各meshの `receiveShadow`
- `ContactShadows`
- マテリアルのroughness

小さなメモやピンまで影を落とす必要は通常ありません。
パフォーマンスを下げずに見栄えを整えるなら、まず大きな家具と床の接地影を優先します。

影が強すぎる場合は、オブジェクトの色を明るくする前に、ライトや `ContactShadows` を確認します。

---

## 14. よくある失敗

### オブジェクトが消えた

- 壁や床の裏へ移動していないか
- `CameraRig.tsx` で非表示判定に一致していないか
- 同じ位置に別のオブジェクトが重なっていないか

### 扉や板のように見える

- 枠だけが前面へ出て、ガラスや内側が壁に隠れていないか
- 奥行きの厚いBoxを追加していないか
- 回転したgroup内で、ローカル座標の向きを取り違えていないか

### 家具を変えたら後付け装飾が消えた

`CameraRig.tsx` の探索条件が色・scale・位置に依存している可能性があります。
変更した家具に対応する判定を更新します。

### カメラが対象を外す

対象を動かしたのに `scene-config.ts` のLOOK_ATを更新していない可能性があります。

---

## 15. 変更時のおすすめ手順

1. `feature` ブランチを最新にする
2. 変更対象を一つに絞る
3. 外側groupのpositionから調整する
4. 初期表示を確認する
5. クリック後の個別カメラを確認する
6. PC幅とモバイル幅を確認する
7. Vercel Previewを確認する
8. 問題なければ `master` へマージする

一度に複数の家具・カメラ・ライトを変更すると、どの変更で崩れたか分かりづらくなります。
特に見た目の調整は、小さなコミットで進める方が安全です。
